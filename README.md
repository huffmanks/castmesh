# CastMesh

A universal casting app for sharing media between devices, regardless of platform.

Use one device as the sender and another as the receiver, whether you're casting from a phone, computer or TV.

## Platforms

- **Desktop:** macOS, Windows, Linux
- **Mobile:** Android
- **TV:** Samsung TV, Android TV, Fire TV

## How it works

CastMesh connects devices running the app or a supported web browser, making it easy to send and receive media across platforms.

## Project structure

CastMesh is a monorepo with shared code and platform-specific apps.
